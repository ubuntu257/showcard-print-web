# 🏷️ 쇼카드 가격표 인쇄 웹앱

엑셀 업로드로 곤도라 진열장 쇼카드 가격표를 A4로 인쇄하는 정적 웹앱.

## 사용법

- **온라인:** GitHub Pages 주소로 접속해서 바로 사용
- **로컬 실행:** `node server.js` 후 http://localhost:7788

## 엑셀 컬럼 순서

| 열 | 내용 |
|----|------|
| A | 상품명 |
| B | 브랜드명 |
| C | 가격 (숫자) |
| D | 할인문구 (선택) |
| E | 행사가격 (선택) |

## 구성

- `index.html` — UI
- `app.js` — 엑셀 파싱 · 카드 렌더링 · A4 인쇄 로직
- `style.css` — 스타일
- `server.js` — 로컬 정적 서버 (배포에는 불필요, 로컬 실행용)

빌드 과정 없는 순수 정적 사이트입니다. 엑셀 처리는 브라우저에서 CDN(xlsx)으로 수행합니다.
